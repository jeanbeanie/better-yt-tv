# Client

React + TypeScript SPA built with Vite.

## Development

```bash
pnpm --filter client dev
```

## Scripts

| Command | What it does |
|---|---|
| `pnpm --filter client dev` | Start the Vite dev server |
| `pnpm --filter client build` | Type-check and build for production |
| `pnpm --filter client lint` | Lint the client |
| `pnpm --filter client test` | Run tests (vitest + React Testing Library) |

See the [root README](../README.md) for full project setup.
